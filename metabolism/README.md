# metabolism for CitizenFX

This metabolism project has been automatically generated by the CitizenFX resource template.

To edit it, open `metabolism.sln` in Visual Studio.

To build it, run `build.cmd`. To run it, run the following commands to make a symbolic link in your server data directory:

```dos
cd /d [PATH TO THIS RESOURCE]
mklink /d X:\cfx-server-data\resources\[local]\metabolism dist
```

Afterwards, you can use `ensure metabolism` in your server.cfg or server console to start the resource.
